Large-Scale Imaging Server
Implementation — Microtek

Microtek has deployed custom PC images for Colorado schools and organizations for over 20 years. When their imaging workflow hit a scaling wall, we implemented a new PXE-based imaging server using the Macrium Reflect Deployment Toolkit — bringing their capacity to over 2,000 consistent deployments per week.

Client
Microtek (microtek-co.com)
Sector
Education Technology
Delivered via
Information Systems Integrators (ISI)
Stack
PXE · Macrium Reflect Deployment Toolkit · WinPE

The Situation

Microtek is a Colorado-based education technology firm that has been building and deploying custom PC images for schools, districts, and organizations for more than two decades. Their work covers everything from initial image creation to large-scale rollouts — custom configurations, application packages, and security baselines tailored to each client's environment.

As client demand grew and PC deployments got more complex, their existing imaging infrastructure couldn't keep up. The process relied heavily on technician time per machine and lacked the centralized control needed to scale consistently across large orders. They needed an imaging server that could handle high-volume deployments reliably — and do it without proportionally growing their labor costs.

This engagement was delivered through Information Systems Integrators (ISI), where I was responsible for the technical implementation from design through handover.

The Challenge

  • Existing imaging process was heavily manual — each machine required direct technician interaction, creating a hard ceiling on throughput
  • No centralized imaging server meant images were managed inconsistently across multiple drives and machines
  • Deploying image updates required touching every machine individually — no network-push capability
  • Growing client order volume was outpacing the capacity of the existing workflow
  • Inconsistent deployment outcomes created QA rework on a percentage of machines at each rollout
  • No documented deployment standard — institutional knowledge lived with individual technicians

The Approach

The core of the solution was a PXE-based imaging pipeline: machines boot from the network, connect to the imaging server, and receive a fully configured image without a technician needing to touch individual media. The Macrium Reflect Deployment Toolkit provided the image management, deployment orchestration, and the WinPE-based boot environment that made it all work at scale.

  • Infrastructure assessment: Documented the existing imaging workflow end-to-end — where technician time was spent, where errors were introduced, and what the hard throughput limits were with the current process. This drove the server sizing and network configuration decisions.
  • Imaging server build: Configured the dedicated imaging server with appropriate storage for image libraries, redundancy for the deployment environment, and network connectivity to support simultaneous multi-machine deployments without bandwidth becoming the bottleneck.
  • PXE boot environment: Configured DHCP options and TFTP to serve the WinPE boot environment to client machines on the network. Any compatible machine on the deployment VLAN could network-boot directly into the imaging environment without local media.
  • Macrium Reflect Deployment Toolkit setup: Installed and configured the Deployment Toolkit on the imaging server. Built out the deployment profiles — mapping image versions to hardware targets, configuring post-image tasks (driver injection, hostname assignment, domain join sequencing), and setting up the deployment menu that technicians interact with during a rollout.
  • Image library and management: Worked with Microtek's team to capture clean reference images for their current client base. Established a versioning convention so image updates could be tracked, tested, and promoted to production without disrupting active deployment profiles.
  • Testing and validation: Ran deployment tests across the hardware SKUs in Microtek's active client base — verifying image integrity, driver compatibility, and post-image state on each target. Identified and resolved a driver injection issue on one hardware line before the system went live.
  • Documentation and handover: Documented the full deployment workflow, image versioning process, and troubleshooting procedures. Walked Microtek's technical staff through the system so they could manage it independently after handover.

Outcomes

2,000+
PCs deployable per week with the new imaging server — consistently, at scale
Network
PXE boot — no local media required; machines deploy from the network automatically
Centralized
Single image library with version control — updates pushed from one location to all deployment profiles
Scalable
Architecture built to scale further — additional imaging capacity can be added without redesign

The shift from manual, per-machine imaging to a centralized PXE deployment pipeline fundamentally changed Microtek's capacity ceiling. Before, throughput was a direct function of technician headcount. After, technicians manage the process rather than executing it machine by machine — freeing them to handle quality checks, client communication, and the edge cases that actually require human judgment.

Microtek continues to operate the system and has expanded its client base since the implementation. Their own words: "After deploying our newest imaging server, Microtek can consistently deploy a custom image to over 2,000 computers a week and can scale even further with your needs."
